## Autonomous systems and physical AI

My current work includes simulated vehicle control, learned continuous policies and policy-governed camera/radar data processing. Physical AI, robot learning and reliable autonomy are research directions I want to develop further. The present evidence comes from simulation and prototypes; physical-robot deployment has not been established.

The [braking controller](https://github.com/FerasElghandour/autonomous-braking-simulation) uses deterministic time-to-collision logic. The [Tennis policy](https://github.com/FerasElghandour/tennis-reinforcement-learning) is learned shared-policy DDPG with local-state critics. They demonstrate different approaches to control.
